# Tableau Public dashboard

**Live dashboard:** [Healthcare Cost Overview](https://public.tableau.com/app/profile/ece.mutlucan/viz/HealthcareCostOverview/Dashboard1?publish=yes)

The Tableau workbook is published on Tableau Public. A local `.twb` or `.twbx` workbook was not among the files supplied for this repository.

The Python notebook generates `data/processed/tableau_data.csv` from the matched rows in the local workbook preview extracts. Before comparing figures, verify that the published dashboard data source and the notebook output cover the same records.
